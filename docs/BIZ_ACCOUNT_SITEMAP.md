# 開戶文件通｜Sitemap（MVP）

```text
/
├── /services                    # 服務介紹／文件清單／FAQ
├── /legal/privacy
├── /legal/terms
├── /auth/login                  # 沿用既有電郵註冊／登入
├── /workspace                   # 客戶控制台
│   ├── /apply/[step]            # 八步申請
│   ├── /documents               # 文件中心
│   ├── /supplements             # 補件
│   ├── /progress                # Timeline + WhatsApp 紀錄
│   └── /account
└── /biz-admin                   # 後台申請列表（本機 MVP）
    └── /[id]                    # 詳情 Tabs + 文件審核
```

貸款產品路由（`/app`、`/apply`、`/admin` 案件）保留。
